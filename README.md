# 考公岗位信息助手

面向**金融专业**考生的公务员岗位查询与竞争度分析桌面应用。内置国考、浙江省考、山东省考、上海市考、**浙江选调**五类考试的官方职位表，支持按地区 / 专业 / 学历 / 政治面貌 / 基层年限多维筛选，并给出逐岗进面分、缴费人数与竞争比。

> 一句话定位：不做「考公鸡汤」，只把**能报名的那几千个岗位**按真实数据摊开给你看。

## 功能

| 页面 | 作用 |
|---|---|
| 岗位查询 | 五类考试并行筛选，本科可报 / 专业关键词 / 地区 / 政治面貌 / 基层年限 |
| 竞争度分析 | 按数据集汇总招录规模、竞争比 TOP15 与「最容易上岸」TOP10 |
| 对比与收藏 | 最多 4 个岗位横向对比，收藏、备注评价（本地持久化） |
| 备考辅助 | 考试时间线、节点提醒（14 天内自动横幅）、备考任务清单 |
| 数据管理 | 数据完整度体检、各地市招录概况、Excel 导入 / 导出 |

## 数据覆盖

|---|---|---|---|---|---|
| 国考 | 2026 | 2419 | 4326 | 97% | 官方不公布逐岗 |
| 浙江省考 | 2026 | 4004 | 5262 | 85% | 缴费人数 100% |
| 山东省考 | 2026 | 5914 | 7790 | 68% | 官方不公布逐岗 |
| 上海市考 | 2026 | 1203 | 2393 | — | 官方不公布逐岗 |
| 浙江选调 | 2027 | 621 | 850 | — | 官方不公布逐岗 |

- **合计 14,160 条真实职位**，每条带 `source` 来源 URL。
- 浙江选调 621 岗 / 850 人，与官方公告完全一致（常规选调 664 = 省市机关 195 + 县乡机关 469，定向紧缺 186）。
- 缺口全部**显式标注**，不做数字填充。

## 数据诚实性

1. **绝不编造**：查不到的字段填 `null`，在 `notes` 里说明口径。
2. **口径必须写清**：进面分有「原始总分 200 分制」「折合分 100 分制」「笔试成绩 100 分制」三套，跨省不可直接比较，界面已用标签区分。
3. **机关级汇总条目会打「汇总」标签**，与真实可投递职位严格分开。
4. 官方不公布逐岗报名人数时，宁可留空也不估算。

## 快速开始

```bash
npm install          # 首次安装（Electron 二进制，国内可设 ELECTRON_MIRROR 镜像）
npm start            # 启动
```

Windows 也可直接双击 `启动考公助手.bat`。

> 需要 Node.js 18+。Electron 二进制下载若卡住，参见《交接文档.md》§7 的镜像与手动解压办法。

## 目录结构

```
gongkao-app/
├─ main.js                # Electron 主进程（窗口、外链、GPU 兜底）
├─ renderer/
│  ├─ index.html          # 五个标签页
│  ├─ app.js              # 全部业务逻辑（筛选/排序/图表/导入导出）
│  ├─ style.css           # 样式
│  └─ lib/xlsx.full.min.js
├─ data/                  # 内置数据集（JSON，每条带 source）
├─ 启动考公助手.bat        # 启动器（纯 ASCII，勿加中文）
└─ 交接文档.md             # 完整开发交接文档（含取数方法、口径、踩坑记录）
```
